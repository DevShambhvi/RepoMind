# RepoMind

## Product Vision

RepoMind is not another AI chatbot.

It is an AI Engineering Workspace.

A place where developers explore, understand and reason about large codebases naturally.

Imagine if GitHub, Notion and an editorial architecture magazine had a child.

The experience should feel calm, premium and intelligent.

The interface should disappear so the engineering thinking becomes the focus.

---

# Design Philosophy

Less Dashboard.

More Workspace.

Less SaaS.

More Operating System.

Less AI.

More Engineering.

---

# Emotional Goals

The interface should feel

• Calm
• Thoughtful
• Premium
• Editorial
• Spacious
• Timeless
• Human
• Quiet
• Intelligent

NOT

• Futuristic
• Cyberpunk
• Neon
• Hacker
• Blue gradients
• Glass everywhere

---

# Visual Language

Background

Warm off-white

Soft paper texture

Very subtle grain

Large whitespace

Rounded corners

Minimal borders

Warm charcoal text

Muted orange accents

---

# Typography

Editorial serif

ONLY

Hero titles

Page titles

Landing page headings

Everything else

Modern sans-serif

Readable

Comfortable

Professional

---

# Component Philosophy

Every card feels physical.

Every shadow is soft.

Every border is thin.

Nothing screams for attention.

Everything has hierarchy.

Spacing is more important than color.

---

# Motion

Small.

Meaningful.

Elegant.

Never flashy.

Animations should explain interaction.

Not show off.

---

# Icons

Lucide only.

No mixed icon packs.

---

# Layout

Large margins

Comfortable spacing

Three-column workspace

Editorial landing page

Generous whitespace

Minimal visual noise

---

# Engineering Feel

The user should feel like

"I'm inside an IDE."

Not

"I'm inside ChatGPT."
